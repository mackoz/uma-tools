uma-tools

Uma Musume: Pretty Derby race simulator and toolset.

  • Umalator (Global)Compare two umas' stats and skills on a course
  • Umalator (JP)Same tool, JP server data
  • Skill Visualizer (Global)See where a skill activates on a course
  • Skill Visualizer (JP)Same tool, JP server data
  • Build PlannerSkill list + region overlay for a reference horse
  • Course ImagesExport course diagrams as PNG
  • UmadleWordle, but it's an uma
  • RougelikeWordle, but it's a hex color
